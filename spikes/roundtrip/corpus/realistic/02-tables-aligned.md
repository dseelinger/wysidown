Compact form:

|a|b|c|
|-|:-:|-:|
|1|2|3|
|x|y|z|

Without leading and trailing pipes:

Name | Value
--- | ---
alpha | 1
beta | 2

Cells with inline formatting and an escaped pipe:

| Code | Meaning |
| ---- | ------- |
| `a \| b` | either a or b |
| **bold** | strong emphasis |
| [link](https://example.com) | a link |
| ~~old~~ new | strikethrough |
