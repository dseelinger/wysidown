# Wysidown

WYSIWYG editing for GitHub Flavored Markdown. Text you do not edit is saved byte for byte, so a
one-word change is a one-word diff.

Open a Markdown file, then choose **Reopen Editor With… › Wysidown**. Undo, redo and save are VS
Code's own, and changes made in another editor of the same file show in Wysidown as you make them.
